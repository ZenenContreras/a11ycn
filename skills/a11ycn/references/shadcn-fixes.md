# shadcn and Radix fixes

These snippets match the components generated by the shadcn CLI. Radix supplies the behavior. The accessible name still has to be in your JSX.

## Icon button

```tsx
<Button type="button" size="icon" className="size-10" aria-label="Open menu">
  <Menu />
  <span className="sr-only">Open menu</span>
</Button>
```

`size="icon"` from the current shadcn preset is usually 40px. A custom `size-5` or `h-5 w-5` class drops the target under 24px (WCAG 2.5.8).

## Dialog, alert dialog, sheet, drawer

```tsx
<DialogContent>
  <DialogHeader>
    <DialogTitle>Delete account</DialogTitle>
    <DialogDescription>This permanently removes the workspace.</DialogDescription>
  </DialogHeader>
</DialogContent>
```

Use `AlertDialogTitle`, `SheetTitle`, or `DrawerTitle` for those components. When the title should not be visible:

```tsx
<DialogTitle>
  <VisuallyHidden>Edit profile</VisuallyHidden>
</DialogTitle>
```

Do not remove the title. Do not set `aria-hidden` on `DialogContent`.

## Form fields

Placeholder text is not a label.

```tsx
<FormItem>
  <FormLabel>Email</FormLabel>
  <FormControl>
    <Input type="email" autoComplete="email" />
  </FormControl>
  <FormMessage />
</FormItem>
```

Outside `Form`, pair `Label` and the control:

```tsx
<Label htmlFor="email">Email</Label>
<Input id="email" type="email" autoComplete="email" />
```

`FormMessage` already wires `aria-describedby` and the invalid state. A hand-written error needs both:

```tsx
<Input id="email" aria-invalid="true" aria-describedby="email-error" />
<p id="email-error">Enter a valid email.</p>
```

## Focus ring

shadcn buttons already ship a `focus-visible:ring`. Do not add `outline-none` or `focus:outline-none` unless the same class list includes `focus-visible:ring-*` or `focus-visible:outline-*`.

## Checkbox

```tsx
<Checkbox id="terms" />
<Label htmlFor="terms">I agree to the terms</Label>
```
