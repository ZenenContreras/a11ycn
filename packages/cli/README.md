# a11ycn

Deterministic WCAG 2.2 checks for React, Next.js, Tailwind, and shadcn/ui.

```bash
npx a11ycn audit ./src --fail-on serious
```

The package is ready to publish with provenance (`publishConfig.provenance`). It is not on npm yet. See the repository README for the release steps.

https://github.com/ZenenContreras/a11ycn
